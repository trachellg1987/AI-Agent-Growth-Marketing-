# 04 - Tool use with Python: client-program summary

Python reads a client-program export and counts live and inactive programs per VAS
product. The model receives only the column names and those counts, never client rows,
and suggests where account managers should focus.

This is the core pattern of the repo: **code does the math, the model explains**, and
client-level data stays out of the prompt.

## Run

```bash
python 04-tool-use-python/agent.py --stats-only   # counts only, no model
python 04-tool-use-python/agent.py --dry-run      # show the exact prompt
python 04-tool-use-python/agent.py                # live run (needs an API key)
python 04-tool-use-python/agent.py --csv my-export.local.csv --question "Which product needs a win-back play?"
```

## Input

[sample-vas-client-programs.csv](sample-vas-client-programs.csv) (fictional, 12 rows):

| Column | Meaning |
| --- | --- |
| `client_id` | Fictional ID |
| `client_type` | `large_issuer`, `regional_issuer`, `acquirer`, `merchant`, `fintech` |
| `vas_product` | Fictional product name |
| `status` | `active` or `inactive` |
| `start_date` | `YYYY-MM-DD` |
| `source` | `account_manager`, `webinar`, `email`, `workshop` |

Name real exports `*.local.csv` or keep them in `data/`; both are git-ignored.
