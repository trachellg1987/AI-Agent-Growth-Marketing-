# Pilot proposal

## When to use

A client is engaged and a pilot is the next step.

## Inputs

Client type (fictional in examples), product, client goals, constraints (security review, procurement).

## Steps

1. Define success criteria with the client; never pre-fill expected results.
2. List data the pilot needs and who approves access.
3. Set a decision date and what happens at each outcome.

## Output

One-page outline: objective, scope, success criteria, timeline, roles, data and security review, decision.

## Guardrails

- Success criteria are targets to measure, not promises.
- Large issuers often need procurement and security review first; plan time for it.
