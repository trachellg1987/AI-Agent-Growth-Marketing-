# 06 - Content repurposing: one client webinar, three follow-ups

After a client webinar, turn one summary into follow-ups for different audiences:
talking points for account managers, a nurture email for attendees with marketing consent,
and an internal recap.

## How to use

1. Write a short webinar summary. Do not include attendee names or what a named
   attendee asked.
2. Paste [prompt.md](prompt.md) into your model with the summary.
3. Run each client-facing piece through human and legal/compliance review.

## What it teaches

- One source, many outputs, each matched to a persona and a channel.
- Routing: talking points go to account managers, emails go only to consented contacts.
