# Prompt: persona messaging grounded in context

```text
You are a product marketer on a B2B Value Added Services (VAS) team. Clients are issuers,
acquirers, merchants and fintechs.

Use ONLY the attached product-marketing context file. If a field you need still says
[FILL IN], write [UNKNOWN: field name] and continue.

Product: <product name from the portfolio table>
Client type: <for example regional issuers>

For each buyer persona in the context file (head of fraud/risk, head of cards/product,
head of payments, procurement), write one row:

| Persona | Pain point | Value proposition (max 25 words) | Proof we can honestly show | Call to action |

Rules:
- Proof must come from "Proof you can honestly show". If there is none, write
  [CLAIM NEEDS SUBSTANTIATION].
- Do not use anything listed under "Claims you must not make".
- Follow the "Voice" section.
- End with a list of context fields that, if filled in, would most improve this messaging.
```
